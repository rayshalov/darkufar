# Darkufar — Тёмная тема для Куфара

> Chrome расширение, добавляющее удобную тёмную тему для сайта [kufar.by](https://www.kufar.by)

---

## ✨ Возможности

- 🌙 **Тёмная тема** — мягкий тёмный интерфейс для всех страниц kufar.by
- ⚡ **Мгновенное применение** — тема применяется до рендера страницы (без мигания)
- 🎛️ **Яркость и контраст** — настраиваемые параметры через popup
- 💾 **Сохранение настроек** — состояние запоминается между сессиями
- 🔄 **Динамический контент** — тема применяется к элементам, загружаемым через JS
- 🛡️ **Только kufar.by** — расширение работает только на домене kufar.by

## 🚀 Установка для разработки

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/your-username/darkufar.git
cd darkufar

# 2. Установите зависимости (для генерации иконок)
npm install

# 3. Сгенерируйте иконки
npm run icons

# 4. Загрузите в Chrome
# - Откройте chrome://extensions
# - Включите "Режим разработчика"
# - Нажмите "Загрузить распакованное"
# - Выберите папку darkufar
```

## 📦 Сборка для Chrome Web Store

```bash
npm run build
# Создаст файл darkufar-v1.0.0.zip для загрузки в Chrome Web Store
```

## 📂 Структура проекта

```
darkufar/
├── manifest.json          # Манифест расширения (MV3)
├── background/
│   └── background.js      # Service Worker
├── content/
│   ├── content.js         # Контент-скрипт
│   └── dark-theme.css     # CSS тёмной темы
├── popup/
│   ├── popup.html         # Интерфейс popup
│   ├── popup.css          # Стили popup
│   └── popup.js           # Логика popup
├── icons/                 # Иконки расширения (генерируются)
├── scripts/
│   ├── generate-icons.js  # Генератор иконок
│   └── build.js           # Скрипт сборки
└── package.json
```

## 🎨 Цветовая схема

| Элемент | Цвет |
|---------|------|
| Основной фон | `#121212` |
| Карточки | `#1a1a1a` |
| Фон секций | `#1e1e1e` |
| Текст | `#e8e8e8` |
| Вторичный текст | `#a0a0a0` |
| Акцент (Куфар green) | `#00AD64` |
| Бордеры | `#333333` |

## 🔒 Разрешения

- `storage` — сохранение настроек
- `activeTab` — доступ к активной вкладке
- `*://*.kufar.by/*` — только домен Куфара

## 📋 Загрузка в Chrome Web Store

1. Сборите ZIP: `npm run build`
2. Откройте [Chrome Web Store Developer Dashboard](https://chrome.google.com/webstore/devconsole)
3. Нажмите **"Add new item"**
4. Загрузите `darkufar-v1.0.0.zip`
5. Заполните описание, скриншоты и отправьте на модерацию

> ⚠️ Для публикации в Chrome Web Store требуется разовый взнос $5 за регистрацию аккаунта разработчика.
