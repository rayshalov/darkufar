# Darkufar — Тёмная тема для Куфара

> Chrome расширение, добавляющее удобную тёмную тему для сайта [kufar.by](https://www.kufar.by)

---

## Возможности

- **Тёмная тема** — мягкий тёмный интерфейс для всех страниц kufar.by
- **Мгновенное применение** — тема применяется до рендера страницы (без мигания)
- **Яркость и контраст** — настраиваемые параметры через popup
- **Блокировщик рекламы** — скрывает рекламные баннеры и ставочников
- **Сохранение настроек** — состояние запоминается между сессиями
- **Только kufar.by** — расширение работает только на домене kufar.by

---

## Установка

1. Скачай `darkufar-v1.1.0.zip` со страницы [Releases](../../releases)
2. Распакуй архив в любую папку
3. Открой Chrome и перейди на `chrome://extensions`
4. Включи **Режим разработчика** (переключатель справа вверху)
5. Нажми **Загрузить распакованное** и выбери распакованную папку

## Структура проекта

```
darkufar/
├── manifest.json          # Манифест расширения (MV3)
├── background/
│   └── background.js      # Service Worker
├── content/
│   ├── content.js         # Контент-скрипт
│   ├── dark-theme.css     # CSS тёмной темы
│   ├── adblock.js         # Блокировщик рекламы
│   └── adblock.css        # CSS блокировщика
├── popup/
│   ├── popup.html         # Интерфейс popup
│   ├── popup.css          # Стили popup
│   └── popup.js           # Логика popup
└── icons/                 # Иконки расширения
```

## Разрешения

- `storage` — сохранение настроек
- `activeTab` — доступ к активной вкладке
- `*://*.kufar.by/*` — только домен Куфара
